## 4. Структура сторінки та компоненти

### 4.1. Навігація (`<nav>`)
- **Позиціонування:** `sticky` у верхній частині екрана з `backdrop-filter: blur(6px)`.
- **Елементи:**
  - Логотип «Chornylo» з іконкою пера.
  - Навігаційне меню зі швидкими якірними посиланнями (`#types`, `#anatomy`, `#care`).

### 4.2. Головний екран (`<header class="hero">`)
- **Компонування:** 2-колонкова асиметрична сітка (`1.1fr` / `0.9fr`).
- **Контент:** Заголовок `h1`, лід-абзац, мета-блок характеристик.
- **Візуальний блок (`.nib-stage`):** Анімована пляма чорнила, векторне перо, анімований розчерк.

### 4.3. Каталог видів ручок (`<section id="types">`)
- **Компонування:** Модульна сітка 3×2 (`grid-template-columns: repeat(3, 1fr)`).
- **Картки інструментів:**
  1. `01 · Класика` — **Перова**
  2. `02 · Повсякдення` — **Кулькова**
  3. `03 · Гібрид` — **Роллер**
  4. `04 · Ескіз` — **Гелева**
  5. `05 · Церемонія` — **Каліграфічна**
  6. `06 · Тимчасове` — **Механічний олівець**

### 4.4. Будова перової ручки (`<section id="anatomy">`)
- **Компонування:** 2 колонки (Схематичне векторне креслення + список компонентів з 4 елементів).

### 4.5. Догляд та ритуал (`<section id="care">`)
- **Стилістика:** Інверсна темна тема (фон `--ink`, світлий текст `--paper`).
- **Компонування:** 4-колонкова сітка правил тривалого використання.

### 4.6. Цитата (`<section class="quote">`) та Підвал (`<footer>`)
- Цитата письменників курсивом та лаконічний підвал із копірайтом.

## 5. Адаптивність та Media Queries (Responsive)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           СХЕМА АДАПТИВНОСТІ                                │
├──────────────────────┬───────────────────────────┬──────────────────────────┤
│ 🖥️ Десктоп (>860px)  │ 📱 Планшет (541px - 860px) │ 📱 Телефон (≤540px)      │
├──────────────────────┼───────────────────────────┼──────────────────────────┤
│ Hero: 2 колонки      │ Hero: 1 колонка           │ Hero: 1 колонка, compact │
│ Типи: 3 колонки      │ Типи: 2 колонки           │ Типи: 1 колонка          │
│ Анатомія: 2 колонки  │ Анатомія: 1 колонка       │ Анатомія: 1 колонка      │
│ Догляд: 4 колонки    │ Догляд: 2 колонки         │ Догляд: 1 колонка        │
│ Навігація: повна     │ Навігація: логотип        │ Навігація: компактна     │
└──────────────────────┴───────────────────────────┴──────────────────────────┘
```

- **Планшетний брейкпоінт (`@media (max-width: 860px)`):**
  - Секція Hero: 1 колонка, зменшений розмір пера та плями.
  - Каталог типів: 2 колонки (`repeat(2, 1fr)`).
  - Будова (Anatomy): 1 колонка (схема над списком).
  - Секція догляду: 2 колонки (`repeat(2, 1fr)`).
  - Меню навігації ховається для збереження простору.

- **Мобільний брейкпоінт (`@media (max-width: 540px)`):**
  - Всі сітки перешиковуються в 1 колонку (`repeat(1, 1fr)`).
  - Блок мета-характеристик у Hero стає вертикальним (`flex-direction: column`).
  - Компактні відступи секцій (`padding: 60px 0;`).

- **Доступність (Accessibility):**
  - `@media (prefers-reduced-motion: reduce)` вимикає анімації для чутливих користувачів.
  - Чіткі фокусні контури (`:focus-visible`).
